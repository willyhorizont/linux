### SPRM output example (self explanatory)
```
 T 59.0°C | C   9.6% | G  28.0% | M  3.25/15.45GB | D 158.19/250.39GB | R       0B/s | W       0B/s | ▼       0B/s | ▲       0B/s |
```
```
        T = Temperature                 
        C = Total CPU Usage             
        G = Total GPU Usage             
        M = Total Memory Usage          
        D = Total Disk Usage            
        R = Total Disk Read             
        W = Total Disk Write            
        ▼ = Average Download Rate       
        ▲ = Average Upload Rate         
```
