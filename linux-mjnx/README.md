# Linux Mjnx
## Ultra Lightweight Debian Based Linux Distro for Older Hardware

## Install
```
su -c "apt update && apt install --no-install-recommends -y curl ca-certificates"
mkdir -p ~/linux-mjnx
curl -L -o ~/linux-mjnx/install.sh https://willyhorizont.github.io/linux-mjnx/install.sh
bash ~/linux-mjnx/install.sh
```
